# Client notes

One folder per client: `accounts/<pp-number>-<client-slug>/notes.md`, e.g. `accounts/pp5416-st-leonards-square-dental-care/notes.md`. Claude creates it the first time an account is worked on.

Suggested sections in `notes.md`:

```markdown
# PP0000 - Client name

- **Google Ads ID:**
- **Meta ad account ID:**
- **WhatConverts profile:**
- **GTM container / GA4 property:**
- **Access:** normal / read only / do not touch
- **Usually worked on by:**

## Goals and preferences
(What counts as success, report format and cadence, tone, branding, creative sizes)

## Tracking
(What's tracked and how, known gaps)

## History and decisions
(Dated one-liners: "2026-10-13 IA: switched to booking confirmations as primary goal")
```

Don't put patient-identifying information here.
